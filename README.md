Netflix Clone (Landing Page)

A pixel-perfect frontend clone of the Netflix Landing Page built using HTML, CSS, and JavaScript. This project replicates the layout, typography, responsive design, and dynamic elements of the original Netflix home page.

🚀 Live Demo
- **Live Website:**https://amit-streaming-website.netlify.app/

✨ Features
- **Responsive Layout:** Perfectly aligned for desktop, tablet, and mobile devices using CSS Flexbox & Grid.
- **Dynamic Content Sections:** Customized featured sections showcasing media, downloads, and device availability.
- **Interactive FAQ Accordion:** Interactive toggle behavior for frequently asked questions.
- **Modern UI Components:** Styled landing hero section, call-to-action buttons, and footer links matching Netflix's design system.

🛠️ Tech Stack
- **HTML5:** Semantic markup structure
- **CSS3:** Custom styling, animations, and responsive layout
- **JavaScript (ES6):** Interactive UI functionality
- **Netlify:** Continuous deployment and hosting via GitHub integration
